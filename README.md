# 微观宇宙 · Microcosmos

一个可直接发布的中英双语静态科普网站。通过可交互的三维关系图谱、粒子特写和双缝实验，探索物质结构与量子现象。

## 功能

- **三维关系图谱**：查看 11 类对象及组成、电磁、强作用、弱反应和希格斯场关系；支持旋转、缩放、聚焦和关系筛选。
- **粒子特写**：查询性质、尺度、质量与运动信息，浏览教学动画。
- **能量与速度**：调节自由粒子能量，观察速度与波长的变化。
- **双缝实验**：逐个发射电子或光子，切换路径探测，对比干涉与无干涉分布。
- **显示与操作**：可调节星尘浓度、暂停图谱动画，适配桌面和移动设备。
- **中英双语**：点击页面右上角 `EN` / `中文` 切换语言；浏览器会在允许本地存储时记住选择。

图形、空间位置和时间均为教学示意。页面中的“科学说明与资料来源”提供数值说明和延伸阅读链接。

## 本地运行

无需安装依赖，也无需构建。HTML、CSS、JavaScript 和绘图逻辑均包含在本目录中。

在本目录打开终端，运行：

```sh
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。按 `Ctrl+C` 停止服务。

建议使用支持 Canvas、`dialog` 和现代 JavaScript 的浏览器。网站不依赖 CDN、远程字体或后端服务；点击资料来源链接会打开外部网页。

## 发布到 GitHub Pages

1. 创建 GitHub 仓库，将本目录中的文件上传到 `main` 分支的**根目录**，确保 `index.html` 直接位于仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 分支和 **/ (root)** 目录，然后保存。
5. 等待 GitHub Pages 部署完成，使用设置页显示的网站地址访问。

无需运行构建命令。请保留 `.nojekyll` 文件，并保持脚本、样式与 `index.html` 的相对位置不变。所有站内资源采用相对路径，可部署在 GitHub Pages 的项目子路径下。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面入口 |
| `styles.css` | 布局、配色与响应式样式 |
| `app.js` | 图谱主界面、粒子特写和交互 |
| `data.js` | 粒子资料与科学来源 |
| `relation-data.js` | 图谱关系数据 |
| `relations3d.js` | 三维关系图谱绘制与操作 |

| `lab.js` | 双缝实验 |
| `i18n.js` | 语言切换与动态翻译 |
| `translations-ui.js` | 界面翻译 |
| `translations-science.js` | 科学内容翻译 |
| `translations-lab.js` | 实验翻译 |
| `.nojekyll` | 告知 GitHub Pages 按静态文件发布 |
| `.gitignore` | 排除本地临时文件 |

## 常用键盘操作

- `/`：聚焦粒子搜索。
- `←` / `→`：切换粒子。
- `空格`：暂停或继续图谱动画。
- `Esc`：从双缝实验返回图谱，或关闭打开的对话框。
