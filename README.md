# 微观宇宙 · Microcosmos

一个中英双语的三维微观世界探索网站。点击一颗原子，让镜头进入它的内部，再继续探索原子核和核子；保留星尘、空间视差、粒子资料与波粒二象性实验。

## 点击，向内探索

1. **完整氦原子**：从一颗大的氦-4原子出发，点击本体或“进入内部”。
2. **原子内部**：观察包围中心原子核的电子概率云；云代表本例2个电子的位置概率分布。
3. **原子核内部**：点击原子核，放大查看2颗质子和2颗中子。
4. **核子内部**：点击一颗质子或中子，分别查看 `uud` 或 `udd` 价夸克组分与动态胶子场。

镜头通过放大与位移衔接场景。可拖动旋转、滚轮或双指缩放，点击路径或返回按钮退回外部。电子与夸克没有已知内部结构，它们的入口用于查看性质，不会再虚构下一层组成。

这是教学示意，非等比例的实测影像。电子云中的光点不是电子数量，也不是固定运行轨迹。核子与夸克的位置不是固定排列；核子内部除价夸克外还有胶子场与夸克海。为方便观察，原子核、核子和场景间的相对尺度经过调整。

## 其他功能

- **关系全景**：切换回自由空间中的11类对象与17条关系，浏览组成、电磁、强作用、弱反应及希格斯场关联。
- **粒子特写**：查看独立教学动画、质量、电荷、尺度和运动信息。
- **能量与速度**：调节自由粒子能量，观察速度与波长的变化。
- **双缝实验**：逐个发射电子或光子，切换路径探测，对比干涉与无干涉分布。
- **中英双语**：右上角 `EN` / `中文` 一键切换，浏览器在允许本地存储时记住选择。
- **星尘渲染**：可调浓度、暂停动画。背景星尘营造空间感，不表示实测粒子分布。

光子、中微子与希格斯玻色子有独立知识入口，不能当作氦原子的常驻组成。胶子场是核子内部动力学的一部分。页面的科学说明提供来源与延伸阅读。

## 本地运行

无需安装依赖或构建。在本目录运行：

```sh
python3 -m http.server 8000
```

访问 <http://localhost:8000>。按 `Ctrl+C` 停止。网站不依赖 CDN、远程字体或后端；资料来源链接需联网。

## GitHub Pages

将本目录文件放在 `main` 分支根目录，保留 `.nojekyll`。在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → / (root) → Save**。等待部署完成后，以设置页显示的地址访问。

所有脚本和样式使用相对路径，可部署在项目子路径下。无需构建命令。
